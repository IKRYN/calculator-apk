СБОРКА APK БЕЗ УСТАНОВКИ UBUNTU НА ВАШ ПК

Этот комплект можно собрать через GitHub Actions в облаке. На компьютере Windows потребуется браузер.

1. Создайте аккаунт или войдите на https://github.com
2. Создайте новый репозиторий (New repository), назовите его calculator-apk. Можно сделать Private.
3. Загрузите в репозиторий папку android (файлы main.py и buildozer.spec должны находиться в папке android) и папку .github/workflows/build-apk.yml.
   Удобный способ: на странице репозитория нажмите Add file > Upload files и перетащите файлы/папки. Если загрузка папок не позволяет сохранить структуру, создайте файлы по одному через Add file > Create new file, используя пути:
   android/main.py
   android/buildozer.spec
   .github/workflows/build-apk.yml
   (содержимое buildozer.spec и main.py берите из комплекта.)
4. После загрузки откройте вкладку Actions.
5. Выберите workflow "Build Android APK" и дождитесь зелёного статуса. Первый запуск может занять несколько минут.
6. Откройте завершившийся запуск. Внизу страницы в разделе Artifacts скачайте calculator-apk.
7. Распакуйте архив artifact: внутри будет APK. Перенесите APK на Android и установите. При запросе разрешите установку приложений из данного источника.

Если сборка упадёт (красный статус), откройте её, скопируйте текст ошибки из шага Build APK и отправьте его мне.
